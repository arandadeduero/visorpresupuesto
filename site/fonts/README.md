# Tipografía

- **Outfit** (variable, pesos 100–900), de Google Fonts / Fontsource: paquete npm `@fontsource-variable/outfit` **5.3.0** (descargado con `npm pack @fontsource-variable/outfit`). Licencia **SIL Open Font License 1.1** (`OFL.txt`).
- Ficheros: `outfit-latin-wght-normal.woff2` (alfabeto latino: castellano, €, comillas…) y `outfit-latin-ext-wght-normal.woff2` (latino extendido). Se cargan con `@font-face` en `css/styles.css` y `unicode-range`, sin depender de Google Fonts ni de ningún CDN.
- Para actualizar: `npm pack @fontsource-variable/outfit`, copiar `files/*.woff2` y `LICENSE` aquí y anotar la versión en este fichero.
